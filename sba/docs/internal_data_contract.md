# 실제 심사와 순손실 검증에 필요한 자료

공개 자료 확장은 지역·업종·경기 환경을 보강한다. 개별 회사의 상환 능력과 은행의 최종 현금 손실을 확인하려면 아래 자료가 추가로 필요하다. 지금 공개 자료에 없는 값을 임의 생성하거나 회사 이름 유사도만으로 다른 기업 자료를 확정 연결하지 않는다.

| 묶음 | 최소 필드 | 시점 / 연결 기준 | 용도 |
|---|---|---|---|
| 신청·결정 | application_id, borrower_id, loan_id, 신청·승인·거절 일시, 승인액·한도, 거절 이유, 기관·상품 | 승인 전에 확정된 버전; 일대다 관계 명시 | 승인된 SBA 대출만 본 선택 편향 및 실제 신청 모집단 점검 |
| 재무 | 매출, 영업현금흐름, EBITDA, 현금·유동자산·유동부채, 총부채, 기존 원리금 상환액 | 재무 기준일, 접수일, 심사 시스템에서 처음 사용 가능했던 일시 | DSCR, 레버리지, 유동성, 매출 성장·변동성 |
| 상환·부도 | 월별 약정액·입금액·잔액·미사용 한도·연체일수, 부도·조건변경·매각·조기상환 날짜 | loan_id × 관측일; 삭제·정정 이력 | PD, 최초 부도 정의, EAD, 검열·경쟁 사건 |
| 회수·비용 | 회수액, 담보 처분액, 법무·추심비용, 보증 청구·지급액, 각각의 일자·상대방 | loan_id × 현금흐름 일시; 중복 회수 방지 | 할인된 순손실, LGD, 보증 후 은행 손실 |
| 담보·보증 | 담보 유형·평가액·선순위 채권, 평가일·입수일, 보증 비율·조건·청구 가능성 | 승인 당시와 이후 버전 분리 | 실제 회수 가능액과 의무·권리 |
| 운영·검증 | 은행별 적용 대상, 심사 정책 버전, 의사결정 이유, 재검토 결과, 외부 검증 기록 | 의사결정일 기준 고정 | 기관별 성능, 설명의 적절성, 차별 위험·운영 감시 |

실제 기대손실의 구성은 ‘부도 확률 × 부도 시 잔액 × 부도 시 순손실 비율’이다. 공개 GrossChargeOffAmount / GrossApproval은 마지막 항목을 측정한 값이 아니다. 보증 비율을 공개 상각액에 단순히 곱하거나 빼는 것도 은행의 보증 후 순손실 계산을 대신하지 못한다.

연결은 내부 borrower_id·loan_id를 기본으로 한다. 기관 간 기업 연결은 적법하게 확보한 EIN 또는 검증된 법인 식별자와 유효 기간을 사용하고, 불명확한 연결은 별도 검토 대상으로 남긴다. 공개 데이터로 대체할 수 없는 항목은 결측으로 명시한다.

새 자료가 확보되면 현재 시험 결과에 맞춰 재학습하는 대신, 새로운 시간 구간과 실제 기관의 신청 모집단을 독립 평가용으로 남긴다. 부도·순손실 정의, 적용 대상, 운영 기준을 먼저 확정하고 평가한다.
